# Security

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting](https://github.com/chrisvo/hours-rs/security/advisories/new) for security issues. Do not include exploitable details in a public issue.

Include the affected version, operating system, reproduction steps, and likely impact. Use a synthetic backup or test document where possible. Do not send your personal prayer library, notes, or credentials.

Ordinary bugs and feature requests belong in [Issues](https://github.com/chrisvo/hours-rs/issues/new/choose).

## Supported versions

Security fixes target the latest release and the `main` branch. Older releases do not have a separate maintenance line.

## Local data

Hours stores its library and personal annotations locally. Backups include those annotations. Treat a backup as personal data and keep a separate copy before testing an unfamiliar build.
